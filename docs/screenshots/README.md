# Screenshots

Product UI captures for Sanctum ADE v1 (used in the root README).

Regenerate against a live Letta-compatible API:

```bash
# from repo root
ADE_E2E_API_KEY=… .venv/bin/python scripts/visual_verify.py docs/screenshots
```

Optional: `ADE_VISUAL_UPSTREAM` (default `https://ade.sanctumos.org/proxy.php`), `ADE_PLAYGROUND_AGENT_ID`.
